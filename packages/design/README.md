# @sarj/design

Public Astro component and color scheme library for Sarj.

```bash
npm install --save-dev @sarj/design
```

Import `@sarj/design/starlight.css` once, then compose the typed Astro components. The live component and theme contract is published at [design.sarj.ai](https://design.sarj.ai/).

Public exports:

- `@sarj/design/Breadcrumbs.astro`
- `@sarj/design/CodeComparison.astro`
- `@sarj/design/PageAnchor.astro`
- `@sarj/design/ReferencePage.astro`
- `@sarj/design/RulePager.astro`
- `@sarj/design/catalog`
- `@sarj/design/contracts`
- `@sarj/design/line-diff`
- `@sarj/design/starlight.css`
- `@sarj/design/styles.css`
